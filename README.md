### New Knowledges

#### first name 和 last name 以及full name

1. first name 指名字 

2. last name 指姓氏

3. full name 指全名 为 `first name` + `last name` 

   例如王小明的  `first name`:Xiaoming ,`last name`:Wang,`full name`:Xiaoming Wang
