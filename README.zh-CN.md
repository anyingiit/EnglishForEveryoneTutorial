## 关于本项目

本仓库是 anyingiit 学习《English for Everyone》教材时整理的个人笔记：按级别记录的生词表、练习句子和简短的语法笔记，保存在 [`English for Everyone Tutorial - Notes.md`](<English for Everyone Tutorial - Notes.md>) 中。笔记之外，[`Tutorial Photos/`](<Tutorial Photos>) 目录下还存放了笔记中提到的教材页面的照片。

这里没有需要构建或运行的应用程序；具体含义见下方的[前置条件](#前置条件)和[使用方法](#使用方法)。

## 开始使用

### 前置条件

- 一个能查看 Markdown 的工具，或直接使用 GitHub 自带的渲染即可阅读 [`English for Everyone Tutorial - Notes.md`](<English for Everyone Tutorial - Notes.md>)。不需要编译器、运行时或包管理器。

### 安装

没有任何东西需要安装——本仓库只是笔记和照片，不是一个软件包。获取本地副本：

```sh
git clone https://github.com/anyingiit/EnglishForEveryoneTutorial.git
```

然后用你喜欢的编辑器打开 `English for Everyone Tutorial - Notes.md`，或者直接在 GitHub 上阅读。

## 使用方法

打开 [`English for Everyone Tutorial - Notes.md`](<English for Everyone Tutorial - Notes.md>)，按级别查看生词表和练习题；浏览 [`Tutorial Photos/`](<Tutorial Photos>) 查看对应教材页面的照片。
